# star-chaser
Star shooting space game
=============================================

a / d  -  left / right
s  -  stop
space  -  regular shot, 2 points if long shot (star further than 200px), otherwise 1 point
e  -  super shot for 3 points (super shots only possible if star is further than 450px), only 10 shots per game
p  -  pause the game for 10 seconds

=============================================

Enjoy
