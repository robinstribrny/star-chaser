# star-chaser
Star shooting space game
=============================================

a / d  -  left / right |
s  -  stop |
space  -  regular shot for 1 point, 70 regular shots per game |
e  -  super shot for 3 points (super shots only possible if star is further than 450px), only 10 super shots per game |
p  -  pause the game for 10 seconds

You can catch up to 100 points using bullets, then you have to collect them by starship.
=============================================

Enjoy
